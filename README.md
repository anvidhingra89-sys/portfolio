## ✏️ Customisation

Before publishing, replace these placeholders in `index.html`:

- `YOUR-PROJECT-LINK` → link to The Food Atelier (live site or repository)
- `YOUR-EMAIL` → your email address (used in the `mailto:` link)
- `YOUR-GITHUB-LINK` → your GitHub profile URL

## 🌐 Deployment

The site is static, so it can be hosted for free on **GitHub Pages**:

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under *Source*, choose the `main` branch and the root folder, then save.
4. Your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.
